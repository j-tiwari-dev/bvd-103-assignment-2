# McMasterful Books - Assignment 5

## Features

- Koa REST API
- MongoDB persistence
- Warehouse inventory and shelf management
- Book ordering and fulfilment
- tsoa OpenAPI generation
- Swagger UI
- Generated TypeScript SDK
- Vitest unit tests
- Generated-SDK API integration tests
- GitHub Actions CI

## Install

npm install

## Generate OpenAPI

npm run swagger
npm run routes

## Generate SDK

npm run generate-sdk

## Run Server

npm run start-server

Swagger UI:
http://localhost:3000/docs

## Testing

Unit tests:
npm run test:ci

Generated SDK API tests:
npm run test:api

Type checking:
npm run check-types

Lint:
npm run lint
